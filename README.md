## Sobre o projeto

Site estático desenvolvido para apresentar minha trajetória profissional, unindo relacionamento com o cliente e domínio técnico em dados. Construído do zero em HTML e CSS puro, sem frameworks, com foco em performance e um design minimalista e elegante.

<br/>

## Estrutura

| Seção | Conteúdo |
|---|---|
| Hero | Apresentação e chamada principal |
| Sobre | Resumo profissional e diferenciais |
| Trajetória | Linha do tempo de experiências |
| Competências | Habilidades por área de atuação |
| Projetos | Repositórios e materiais em destaque |
| Conquistas | Resultados e impacto profissional |
| Formação | Graduação, pós-graduação e certificações |
